# Continuous reading script - Turkish
#
# Unlike data/insitu/script-tr.txt, which is read one sentence at a time with a
# pause between each, this is read STRAIGHT THROUGH as a single take, at
# presenting pace, with ordinary breath pauses.
#
# That difference is the point. Three things can only be measured on continuous
# speech, and all three were guesses until this existed:
#
#   1. vad.min_silence_ms - the largest single term in the end-to-end delay.
#      Sentence-by-sentence recordings have artificial gaps between them, so
#      they cannot show whether 500 ms cuts a speaker off mid-clause and 700 ms
#      does not. Only real breath pauses can.
#   2. Partial subtitles (ADR 0008) - how often a provisional reading is
#      revised, and whether the revisions are the harmless kind.
#   3. A clean voice reference. Recorded on a phone rather than the laptop,
#      whose driver gates 16-50% of every file to digital silence.
#
# The text is deliberately loaded with the things that have broken before:
#
#   - "sorum suydu" - the cataphoric construction that made NLLB-600M silently
#     drop the following sentence (ADR 0007)
#   - "degil" - negation carried by a suffix at the very end of the clause,
#     which reverses everything before it
#   - "600.000" - Turkish groups thousands with a full stop, which once had the
#     normaliser spelling it "kirk sifir"
#   - Friulian, ARLeF, Friuli - the proper nouns the hotword list biases toward
#   - sentences from one word to thirty, so the segmenter meets both extremes
#
# HOW TO RECORD
#   Phone, quiet room, phone about 20-30 cm away, one continuous take.
#   Read at the pace you will actually present at - do not over-articulate.
#   If you stumble, keep going; a natural recovery is useful material.
#   Send the file as it is. Do not trim it.
